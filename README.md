# IT326 Data Mining Project

## Project Information
* **Project Description:**[This project aims to apply Data Mining and Machine Learning techniques to analyze student data, classify student performance into specific categories, and uncover hidden patterns related to study habits and academic success. The primary goal is to solve the problem of predicting student achievement and identifying the key demographic, social, and school-related factors that lead to academic success or failure.]
* **Project Objectives:** [Classify student academic performance by categorizing the final_grade class label into distinct performance levels or outcomes (such as pass/fail).  Build and evaluate predictive models to accurately map student study habits and background features to their final grade categories.  Analyze the class distribution of the final grade to understand student success and failure rates within the dataset.  Identify the key factors that significantly influence the final grade to help institutions support struggling students]
* **Project Motivation:** [We chose to work on this dataset and problem because education is a fundamental pillar of long-term societal progress. High student failure rates present a serious challenge to academic institutions. By building automated data mining models, educators and schools can identify at-risk students early, apply proactive corrective measures (such as remedial support), and ultimately improve the quality of education and resource management.]
